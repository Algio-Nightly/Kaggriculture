# Kaggriculture State Representation & Dual-Tower Architecture Report

This document details the **Dual-Tower state representation**, the **raw JSON observation parser mapping**, and the **Siamese 2D-CNN + MLP Late Fusion architecture** implemented for the Kaggriculture JAX model.

---

## 1. Overview & Architectural Goal

Kaggriculture features two independent $10 \times 10$ farm grids (one for Player 0, one for Player 1) along with a shared macro-economy. 

To respect spatial board independence while sharing identical farming physics, we use a **Dual-Tower Siamese Architecture**:
- **Tower A (Own Farm Grid)**: A $10 \times 10 \times 21$ tensor encoded from `obs["farms"][player]`.
- **Tower B (Opponent Farm Grid)**: A $10 \times 10 \times 21$ tensor encoded from `obs["farms"][1 - player]`.
- **Siamese 2D-CNN Backbone**: Shared convolutional weights process both farm grids in parallel.
- **Global MLP Branch**: A dense MLP processes non-spatial market, inventory, time, money, and derived town product demand rates (47 features).
- **Late Fusion**: Concatenates own spatial embedding, opponent spatial embedding, and global scalar embedding into a joint representation feeding the Policy (Actor) and Value (Critic) networks.

```
                   Raw Observation JSON (Dict)
                                │
                    encode_observation(obs)
                                │
        ┌───────────────────────┼───────────────────────┐
        ▼                       ▼                       ▼
   Own Farm Grid       Opponent Farm Grid         Global Vector
 (10 × 10 × 21)          (10 × 10 × 21)           (47 Features)
        │                       │                       │
   Siamese CNN             Siamese CNN             MLP Encoder
  (Shared Weights)        (Shared Weights)      (Scalar Features)
        │                       │                       │
   Own Spatial Vector    Opponent Spatial Vector   Global Vector
      (6400 dims)             (6400 dims)           (128 dims)
        │                       │                       │
        └───────────────────────┼───────────────────────┘
                                ▼
                       Dual-Tower Late Fusion
                           (Concatenate)
                                │
                       Dense Latent Layer
                                │
        ┌───────────────────────┴───────────────────────┐
        ▼                                               ▼
  Actor Policy Head                              Critic Value Head
(Action Logits Prediction)                      (State Value V(s))
```

## 5. Model Integration ([`model/network.py`](file:///c:/Applications%20and%20Development/Kaggriculture/model/network.py))

The extracted features are processed in `ActorCriticNet`:

1. **`SpatialEncoder` (Siamese Shared Weights)**:
   - Input A: `own_grid_tensor` `(Batch, 10, 10, 21)` $\rightarrow$ `own_emb` ($10 \times 10 \times 64 = 6400$ values).
   - Input B: `opp_grid_tensor` `(Batch, 10, 10, 21)` $\rightarrow$ `opp_emb` ($10 \times 10 \times 64 = 6400$ values).
   - Uses the exact same 3-layer 2D-Conv weights (`21 -> 32 -> 64 -> 64`).

2. **`GlobalEncoder`**:
   - Input: `global_tensor` `(Batch, 47)` $\rightarrow$ `global_emb` ($128$ values).
   - 2× Dense Linear layers with ReLU (`47 -> 128 -> 128`).

3. **Dual-Tower Late Fusion**:
   - `jnp.concatenate([own_emb, opp_emb, global_emb], axis=-1)` creates a combined vector of length $6400 + 6400 + 128 = 12928$.
   - Dense layer maps $12928 \rightarrow 256$ hidden latent dimension.

4. **Policy & Value Heads**:
   - `farmer_head`: Predicts discrete action logits over valid farmer commands.
   - `value_head`: Predicts scalar state value $V(s)$ for Critic evaluation.
